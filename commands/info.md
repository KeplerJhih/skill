# Command: /info

此指令用於快速查詢一般資訊或技術概念，**不進行代碼庫掃描 (No Codebase Scan)**。

當你需要查詢通用的編程知識、庫的用法、文檔說明，或者詢問與當前代碼庫無直接關聯的問題時，請使用此指令。

ARGUMENTS: $ARGUMENTS

## 🚫 禁止行為

- **不要**使用 `grep`、`glob` 或 `codebase_search` 等工具掃描代碼庫。
- **不要**讀取專案中的源代碼文件（除非用戶明確指定路徑）。

## 🚀 查詢策略（MANDATORY）

### Step 1：判斷查詢類型

根據用戶的問題，判斷屬於以下哪種類型，並採用對應策略：

| 類型 | 判斷依據 | 查詢策略 |
|---|---|---|
| **A. 框架/庫/SDK 用法** | 提到具體的庫名（React, Laravel, Terraform 等） | **context7 優先** + WebSearch 補充 |
| **B. 工具/服務調查** | 「有什麼推薦」「比較」「選型」 | **多角度 WebSearch**（並行 2-3 個查詢） |
| **C. 概念/原理解釋** | 「什麼是」「如何理解」「原理」 | **知識庫優先** + WebSearch 驗證最新觀點 |
| **D. 最新動態/版本** | 「最新版本」「2026」「changelog」 | **WebSearch 為主**（加年份關鍵字） |
| **E. 疑難排解** | 「錯誤」「error」「怎麼解決」 | **WebSearch 多角度**（錯誤訊息 + 解法） |

### Step 2：執行查詢

#### 類型 A — 框架/庫/SDK 用法

1. 使用 `context7` MCP 工具查詢官方文件：
   - 先用 `resolve-library-id` 找到庫的 ID
   - 再用 `query-docs` 查詢具體文件內容
2. **同時並行** `WebSearch` 查詢社群最佳實踐和範例
3. 整合兩者結果，以官方文件為準，社群資料為補充

#### 類型 B — 工具/服務調查

**必須並行發送至少 2 個不同角度的 WebSearch 查詢**，例如：
- 查詢 1：`"[主題] 推薦 比較 [當前年份]"` — 找綜合比較文
- 查詢 2：`"[主題] official setup guide"` — 找官方文件
- 查詢 3（可選）：`"[主題] alternatives pros cons"` — 找替代方案

#### 類型 C — 概念/原理解釋

1. 先用自身知識庫回答核心概念
2. 用 `WebSearch` 查詢是否有最新的業界觀點或更新
3. 如果是特定框架的概念，搭配 `context7` 查詢官方定義

#### 類型 D — 最新動態/版本

**WebSearch 查詢時必須加入當前年份**，並行查詢：
- 查詢 1：`"[主題] latest release [當前年份]"` 
- 查詢 2：`"[主題] changelog what's new"`

#### 類型 E — 疑難排解

**並行查詢**：
- 查詢 1：完整錯誤訊息搜尋
- 查詢 2：`"[工具/框架] [錯誤關鍵字] solution"` — 找解法
- 查詢 3（可選）：在 GitHub Issues 或 StackOverflow 搜尋

### Step 3：結構化輸出

**所有回覆必須遵循以下格式**：

```
## [查詢主題]

### 核心回答
[直接回答用戶的問題，簡潔有力]

### 詳細說明
[根據查詢結果提供完整的資訊，包含：]
- 關鍵概念或功能說明
- 具體用法、指令、配置範例（如適用）
- 版本/相容性資訊（如適用）

### 比較表（如適用）
| 選項 | 優點 | 缺點 | 適用場景 |
|---|---|---|---|

### 建議
[根據查詢結果給出具體、可操作的建議]

### Sources
- [來源標題](URL)
```

## 適用場景範例

- "React 19 有什麼新功能？" → 類型 D（最新動態）
- "比較 Terraform 和 Pulumi" → 類型 B（工具調查）
- "Laravel queue 的 retry 機制怎麼用？" → 類型 A（框架用法）
- "什麼是 Event Sourcing？" → 類型 C（概念解釋）
- "docker build 出現 OOM error" → 類型 E（疑難排解）

## 區別

- **`/info`**: 查詢**外部**或**通用**資訊，速度快，不消耗代碼搜索資源。
- **一般對話/其他指令**: 可能會觸發代碼庫掃描以提供上下文相關的回答。
